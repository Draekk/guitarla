# GuitarLA

GuitarLA es una aplicación web diseñada para simular un e-commerce de guitarras, con un carrito de compras completamente funcional. Desarrollada utilizando Vite y React, esta aplicación representa mis primeros pasos en el desarrollo con React.

## Características

- Simulación de un e-commerce de guitarras.
- Carrito de compras funcional.
- Interfaz de usuario intuitiva y amigable.

## Tecnologías Utilizadas

- **Vite**: Herramienta de desarrollo rápida y ligera.
- **React**: Biblioteca de JavaScript para construir interfaces de usuario.

## Requisitos

- **Node.js**: Asegúrate de tener Node.js instalado. Puedes descargarlo desde [nodejs.org](https://nodejs.org/).
- **npm**: Node.js incluye npm, el gestor de paquetes de Node.js.

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Draekk/guitarla.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd guitarla
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```

## Uso

Para iniciar la aplicación, ejecuta el siguiente comando:

```bash
npm run dev
```

Esto iniciará la aplicación en modo de desarrollo. Abre tu navegador y visita `http://localhost:5173` para ver la aplicación en funcionamiento.
